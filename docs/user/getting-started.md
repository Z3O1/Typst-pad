# 入门

## 写第一份文档

启动应用后，在写作模式输入：

```typst
= 我的第一份文档

这里是中文正文，也可以写 *粗体* 和 _斜体_。

行内公式：$x^2 + y^2$。

$ sum_(i=1)^n i = (n(n+1))/2 $
```

「格式」菜单可以插入常见结构；输入 `$` 会自动配对。写作模式普通正文按 Enter 开新段落（源码写入两个换行），Shift+Enter 在同段内显式换行；列表优先续写列表项。普通正文可直接编辑，公式或复杂内容进入编辑时显示对应源码。按 `Ctrl+E` 可在源代码模式检查完整文本与预览，详见[编辑模式](editing-modes.md)。

## 保存与导出

使用「文件 → 保存」或 `Ctrl+S`，首次保存时选择 `.typ` 路径。应用没有自动写盘：启动时恢复上次内容是会话恢复，不代表磁盘文件已保存。将空正文保存到已有文件会直接写成空文件。

使用「文件 → 导出 PDF」选择输出位置。预览可能按栏宽重排，PDF 按文档自己的纸型排版；正式提交前打开 PDF 检查分页和完整内容。

相对 `#import` / `#include` 需要先保存主文档。字体和包的设置见[字体与包](fonts-and-packages.md)。

## 窗口与会话

每个窗口编辑一份文档。「文件 → 新建窗口」打开空白副窗口，副窗口不会恢复或覆盖主窗口的上次会话。主窗口默认恢复上次非空内容与文件信息，可在设置中关闭。

打开、重读、新建或关闭时，注意未保存修改提示。状态栏可以查看错误与警告、跳转定位、复制诊断。遇到问题见[限制与排障](troubleshooting.md)。
