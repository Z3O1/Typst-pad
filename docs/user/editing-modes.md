# 编辑模式

[返回文档索引](../README.md) · [快捷键](shortcuts.md)

## 写作模式

默认采用单栏纸张界面，无行号且始终自动折行。纯 markup 的普通段落和标题保持可编辑文字；光标触碰标记时局部露出语法。公式单独就地排版，列表、表格以及含代码/raw/注释的复杂块可能显示为 Typst 排版切片，进入后展开源码。

写作模式是编辑视图，不是 PDF 的完整替身。不能由当前呈现层可靠处理的语法保留源码，渲染失败或未就绪也会退回源码。具体范围见[限制与排障](troubleshooting.md)。

使用「格式」菜单或快捷键添加粗体、斜体、标题、列表、代码、公式、引用或链接。块格式命令无选区时作用于当前整行，有选区时只作用于选区；引用使用 Typst 的 `#quote(block: true)[...]`，不是 Markdown 的 `>`。

写作模式 Enter 优先续写 Typst 列表；普通正文的 Enter 创建新段落（两个源码换行），Shift+Enter 插入 Typst 显式换行（反斜线加换行）。代码、raw、注释和公式等语境沿用单个源码换行，源代码模式也不套用写作段落语义。两种操作都沿用光标左侧缩进，空白行的残余缩进会清除。普通段落间的空白源码行仍可编辑，显示高度贴近 Typst 默认段距；文档或前缀显式设置 `#set par` / `#show par` 时保留原始行高。

**链接**：写作模式里 `#link("url")[文字]` 显示为带链接样式的正文（URL 隐藏、原样留在源码里，光标触到 `#link(` 或 `]` 会露出）。**Ctrl/Cmd+点击**打开链接；普通点击照常把光标放进文字里改字。仍被切片的块（例如带脚注的段落）里的链接是热区，普通点击即打开。

列表的结构化键位：Tab / Shift+Tab 按缩进嵌套与反嵌套一层（4 个空格一档）；Backspace 在**行首 / 标记区 / 体首**做结构动作而不是删字符 —— 空项退格抹掉整条标记、留一个空段落，嵌套项退格先反嵌套一层，行首退格把这一项并进上一项，正文体首退格取消列表（正文变普通段落）。光标已经在正文中间时 Backspace 仍是普通删字；代码 / raw / 注释 / 公式里不套用这些语义，源代码模式也不套用。

## 源代码模式

通过「视图 → 源代码模式」或 `Ctrl+E` 切换。左侧为等宽源码与行号，右侧为整页预览；内联装饰关闭。`Alt+Z` 切换源码折行，不影响写作模式。切换模式保留源码与编辑位置。

## 预览、主题与缩放

写作模式也可通过「视图 → 显示预览栏」打开预览。默认预览按栏宽重新排版，因此换行、分页可能与 PDF 不同；文档显式设置纸张时走固定纸型缩放。编译失败时可能保留最后一次成功预览，请同时查看诊断。

视图菜单可选自动、明、暗主题。`Ctrl+滚轮` 缩放整个界面，也可使用菜单或键盘；范围为 50%–250%，每档 10%。缩放设置会记住，状态栏显示档位；系统 WebView 的实际缩放能力可能有不同上限。
