# 限制与排障

[返回文档索引](../README.md)

## 呈现与编辑边界

| 限制 | 使用建议 |
| --- | --- |
| 单窗口单文档，无文件树或多标签页；副窗口不恢复会话 | 使用独立窗口并显式保存 |
| 预览不跟随编辑器滚动，且栏宽重排可能改变分页 | 正式输出检查导出的 PDF |
| 普通可编辑正文只模拟部分 Typst 标记，引用、标签、简写和转义等可能保留源码 | 切换源代码模式并对照整页预览 |
| 复杂块的 SVG 切片没有文字层 | 浏览器查找、拼写检查和无障碍文本无法读取切片；复制仍可得到源码，而非排版后的纯文字 |
| 表格整块呈现，超大块可能只显示源码；跨页块不保证完整切片 | 在源码模式编辑复杂结构 |
| 脚注正文及裁剪带之外的浮动内容可能不显示 | 查看整页预览或 PDF，不能把写作模式截图当完整输出 |
| 独立公式只提取设置前缀和文档单行顶层 `#let`，不完整执行文档上下文 | 复杂定义可放设置前缀，或对照整页编译；失败时公式保留源码 |
| 列表 Tab/Backspace 尚无完整结构化语义，纯文字复制、可视化表格编辑未提供 | 用源码完成相关操作 |

这些边界对应[渲染设计](../design/rendering-model.md)，不是已承诺的开发计划。浏览器验收也不能替代所有桌面平台的真实手感与性能验证。

## 常见问题

**编译错误或预览没更新**：点击状态栏错误/警告徽标，定位或复制诊断。编译失败会保留最后成功预览；先修复诊断再判断排版。前缀代码、导入文件或包也可能是错误来源。

**相对导入失败**：先保存主文档，确认文件存在并位于同盘/卷；跨盘引用应调整项目位置。在线包首次获取失败时检查网络与包版本，见[字体与包](fonts-and-packages.md)。

**字体没有生效或缺字**：检查英文族名和额外字体目录，留意状态栏警告；生僻字需要覆盖该字符的系统或本地字体。设置字体与文档内显式字体命令可能互相覆盖。

**保存后与上次内容不同**：启动恢复恢复的是会话，不能代替保存到磁盘；副窗口不参与主窗口会话恢复。空正文保存到已有文件会写空文件。不要在确认内容前覆盖原文件。

**缩放不动**：改用「视图 → 放大/缩小」或键盘快捷键，查看状态栏诊断；引擎实际档位可能受平台限制。

**更新失败或不再弹窗**：先尝试「帮助 → 检查更新」；点过「稍后」后不再自动弹窗是预期行为。失败时可从 [Releases](https://github.com/Z3O1/Typst-pad/releases/latest) 手动下载；维护者排查见[更新器](../maintainers/updater.md)。

**浏览器显示“请使用桌面应用版本”**：正常使用应启动安装的桌面应用。前端开发预览不是网页版产品。

仍无法解决时，按[贡献指南](../../CONTRIBUTING.md)提交最小复现、诊断和环境信息。
