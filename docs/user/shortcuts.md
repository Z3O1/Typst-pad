# 快捷键

[返回文档索引](../README.md)

以下按 Windows 键名列出；菜单是操作入口。键盘布局可能影响符号键。

| 操作 | 快捷键 |
| --- | --- |
| 新建 / 打开 / 保存 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` |
| 新建窗口 / 关闭窗口 | `Ctrl+Shift+N` / `Ctrl+W` |
| 重读当前文件 | `Ctrl+R` |
| 设置 / 导出 PDF | `Ctrl+,` / `Ctrl+P` |
| 写作与源代码模式切换 | `Ctrl+E` |
| 源代码模式自动换行 | `Alt+Z` |
| 行注释 / 块注释 | `Ctrl+/` / `Ctrl+Shift+/` |
| 加粗 / 斜体 / 链接 | `Ctrl+B` / `Ctrl+I` / `Ctrl+K` |
| 行内代码 | `Ctrl+Shift+反引号` |
| 行内公式 / 公式块 | `Ctrl+M` / `Ctrl+Shift+M` |
| 一级 / 二级 / 三级标题 | `Ctrl+1` / `Ctrl+2` / `Ctrl+3` |
| 正文 | `Ctrl+0` |
| 无序 / 有序列表 | `Ctrl+Shift+]` / `Ctrl+Shift+[` |
| 引用 / 代码块 | `Ctrl+Shift+Q` / `Ctrl+Shift+C` |
| 界面放大 / 缩小 | `Ctrl+滚轮` 或 `Ctrl+Shift+=` / `Ctrl+Shift+-` |
| 新段落 / 同段显式换行（写作模式普通正文） | `Enter` / `Shift+Enter` |
| 缩进 / 反缩进 | `Tab` / `Shift+Tab`（一档四空格） |
| 收起最上层弹窗 | `Esc` |

输入 `$` 会配对，右侧已有闭合 `$` 时跨过它，空配对上退格会整对删除；代码或注释中不自动配对。在设置弹窗按 Esc 会放弃尚未保存的设置草稿。

键位实现与事件归属见[前端](../development/frontend.md)。
