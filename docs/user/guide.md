# 使用指南

[返回文档索引](../README.md) · [快捷键](shortcuts.md)

## 安装与更新

从 [Releases](https://github.com/Z3O1/Typst-pad/releases/latest) 下载 Windows x64 的 NSIS 安装程序或 MSI 安装包。应用内置 Typst 编译引擎与字体，不需要另装 Typst CLI。Linux/macOS 源码开发见[开发与验证](../development/testing.md)。

主窗口按设置静默检查更新，也可使用「帮助 → 检查更新」。只有点击「下载并安装」才会下载安装；安装前保存文档。「稍后」抑制后续自动弹窗，手动检查可重新打开。失败时可从 Releases 手动下载安装。

## 编辑文档

文档模式显示完整 Typst 编译页。点击正文定位并输入；点击公式或脚本输出，在原位置展开该表达式的完整源码（包括多行），由 Typst 重新编译显示。输入修改原文档，展开标记不会写入文件。Esc 收起源码并重新编译正常排版。文档模式只显示文档本体：没有占位提示、更新提示和右上角按钮，失败与进度看状态栏。无法定位、文档为空或编译失败时，按 Ctrl+E 切到源码模式继续编辑，编辑位置和撤销历史保留；Alt+Z 切换源码折行。

```typst
= 我的第一份文档

中文正文，*粗体*、_斜体_ 和公式 $x^2 + y^2$。

#table(columns: 2, [甲], [乙], [一], [二])
```

「格式」菜单可插入常见结构，输入 `$` 自动配对。文档模式中，正文 Enter 创建新段落，Shift+Enter 显式换行，列表优先续项；代码和公式内仍写单个换行。源码模式直接编辑原文。

窗口变化只缩放页面，不改变分页。主题和界面缩放在视图菜单中设置；暗主题会对整页应用颜色滤镜，图片也会反色。SVG 是字形轮廓，查找、复制和修改在源码编辑器中完成。外部 include 和部分合成/变换内容可能无法精确点击定位，但仍完整显示。

## 保存、导出与会话

Ctrl+S 显式保存；首次保存选择 `.typ` 路径。会话恢复不等于写盘，没有自动保存。保存空正文到已有文件会写空文件。「文件 → 导出 PDF」按源码纸型导出。

每个窗口编辑一份文档。副窗口是空白草稿，不恢复或覆盖主窗口会话。主窗口默认恢复上次内容，可在设置中关闭。打开、重读、新建或关闭时遵循未保存修改确认。

## 字体与包

应用打包思源宋体、Libertinus Serif、New Computer Modern Math 和 DejaVu Sans Mono；中文字体是子集，生僻字可能需要系统字体补充。「设置 → 正文字体」可选择字体并添加额外目录，族名使用字体内部英文名称。文档的 `#set text(font: ...)` 优先于默认设置；整页和 PDF 使用同一配置。

相对 `#import` / `#include` 需要先保存主文档，以保存路径解析，同盘/卷上级目录可用，跨盘/卷不支持。`@local` 读取本地包，`@preview` 首次使用自动下载到缓存，已有缓存可离线使用。路径、字体回退和包目录见[编译后端](../development/compiler-backend.md)。

## 排障

编译失败时保留上次完整结果，并在状态栏给出错误与警告（徽标可点开列表）；预览区不画错误框，也无法从旧页面定位源码。先查状态栏错误，修复源码、前缀、引用或字体配置，再检查排版。未知字体族提示通常需要核对英文族名与目录。

普通浏览器显示「请使用桌面应用版本」是预期行为。开发启动、日志与 WebView 问题见[开发与验证](../development/testing.md)，更新服务问题见[发布与更新](../maintainers/release.md)。提交问题时提供版本、系统、最小 `.typ` 示例和重现步骤，敏感内容先脱敏。
