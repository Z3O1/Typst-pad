## 1. 工作区布局（2026-09-16 起）

```
/home/z301/Typst-pad                  0991fde [main]                 ← 普通目录 = 发布线（0.7.10）
/home/z301/Typst-pad-block-geometry   2e86f7b [feat/block-geometry]  ← 本目录 = 块级渲染线
```

- 两个目录是**同一个 git 仓库的两个 worktree**（共享 `.git`），不是两份克隆 ——
  两边共用一套提交历史与分支，`git worktree list` 能看到彼此。
- 远端：`origin/feat/block-geometry` = `2e86f7b`（已推，已设 upstream）。`main` 没有被这条线碰过。
- **`src-tauri/target` 是软链**：本目录的 `src-tauri/target` →
  `/home/z301/Typst-pad/src-tauri/target`（31G 编译缓存共享，所以本目录**不用重编 Rust**）。
  代价：两个目录同时 `cargo build` / `tauri dev` 会在同一把文件锁上互等
  （`Blocking waiting for file lock on build directory`）。想彻底隔离就
  `rm src-tauri/target && cd src-tauri && cargo build`。
- `.git/info/exclude` 里加了一行 `src-tauri/target`：`.gitignore` 写的是 `src-tauri/target/`
  （**只匹配真实目录**），软链是文件、不被它匹配，于是会以未跟踪文件的身份出现在 `git status` 里。
  **注意：per-worktree 的 `info/exclude` 根本不被 git 读取**（实测 `git check-ignore` 退出码 1），
  所以那行写在**公共目录** `/home/z301/Typst-pad/.git/info/exclude`。这条只影响本机、不进版本库。
- 本目录 `node_modules` 是独立装的（199M，`npm install` 154 个包 / 6s），
  `.svelte-kit` 已 `svelte-kit sync` 过，`npm run dev -- --port 1426` 冒烟过（HTTP 200 / ready 934ms）。

最后一条的实测前后（600px 视口 + 真实夹具，比例 1.32 ≈ 真机 1.333）：

| 场景 | 修前 | 修后 |
| --- | --- | --- |
| 中文长段落 光标进出块的页面高度差 | +22px | **0px** |
| 标题层级 | +19px（照抄 typst 间距时 +40px） | **+3px** |
| 代码与表格 | +45px | **+8px** |
| 源码字号 / 切片字号 | 1.091 | **1.000** |

字号链：Rust `block_geometry::document_text_pt` 按**字符数取众数**量出文档正文 pt（默认 11pt），
随 `compile_blocks` 的 `textPt` 返回 → 前端挂成 `--write-doc-px`（pt × 4/3）→
`.cm-editor` 字号取它、`.cm-content` 行高取 typst 的 `par.leading`（1.65）。
默认文档 = **14.6667px / 24.2px 行盒**；写了 `#set text(size: 12pt)` 的 = **16px / 26.4px**。

## 4. 还没做的 / 未决

**要先做的一件事：真机复验（`npm run tauri dev`，WebView2）** —— 上面所有数字都来自
headless Chromium + 夹具，真机手感尚未验证。该看的七条：

1. 公式里打字的手感（去抖 150ms + 公式先跑 240ms 是否够；实测 12 个字符 → 1 次 `compile_blocks` + 1 次 `compile_math`，帧间隔最大 26ms）
2. 切片上拖选跨块 + Ctrl+C 复制
3. `#link("https://…")[文字]` 点击
4. 整块选中的淡色底（`#d7d4f0` 同款，**不要描边**）
5. `#set` / `#show` / 纯注释行整格隐藏（以及注释是否要跟 `#set` 一样藏起来 —— 用户可能想看见注释）
6. 行尾 Enter 拆分块之后的光标位置
7. **光标进出各块时字号/行距不该有变化**（`2e86f7b` 的目标）

**已知的固有差异（不是 bug，是"源码透镜"的代价，Typora 也一样）**：

- 段落间距：typst `par.spacing` = 1.2em，而源码形态里用户自己敲的空行 = 1.65em；
  两段同时展开时会有约 0.45em 的差。
- **源码比渲染长的块**（表格源码 5 行 vs 渲染 2 行）展开时必然变高 —— 实测 +8px 就是这类。
- 切片上没有文字层：浏览器查找 / 拼写检查 / 无障碍拿不到（取舍见调研文档第十二节）。

**已记在 CLAUDE.md「已知不足」里的**：脚注正文（页底装饰）在写作模式不显示；
表格仍是整块（按行切会把表格线切开）；真机手感/性能未验证。

**不在本分支、但在普通目录（main）里的一件事**：`package-lock.json` 的 `version` 字段还是
`0.7.3`，而 `package.json` / Cargo.toml 已是 `0.7.10`（发版时漏同步）。`npm install` 会自动改成
0.7.10；在 main 上顺手修一下即可。

**没有做的事**（发版权在用户手里）：没有合并 main、没有打 tag、没有动版本号、没有发版。

## 5. 怎么跑

```bash
# 桌面应用（本目录 = 块级渲染线）；Vite 固定 1420，别和普通目录同时开
cd /home/z301/Typst-pad-block-geometry && npm run tauri dev

cd /home/z301/Typst-pad-block-geometry
npm run check        # 类型检查
npm test             # 639 项（35 个文件）

# 浏览器验收（headless Chromium；换端口别跟 tauri dev 抢 1420）
npm run dev -- --port 1425
BROWSER_CHECK_PORT=1425 CDP_PORT=9335 node scripts/browser-check/writing-blocks.mjs
npm run fixtures:blocks
BROWSER_CHECK_PORT=1425 CDP_PORT=9335 node scripts/browser-check/writing-blocks-visual.mjs
BROWSER_CHECK_PORT=1425 CDP_PORT=9335 node scripts/browser-check/writing-blocks-hit.mjs
BROWSER_CHECK_PORT=1425 CDP_PORT=9335 node scripts/browser-check/writing-mode-scenes.mjs
BROWSER_CHECK_PORT=1425 node scripts/browser-check/wysiwyg.mjs
```

验收几个容易踩的点（都是实测踩过的）：

- **同一个 CDP 页面不许两套验收并发跑** —— 会互相改 `localStorage`，
  报 `SecurityError: Failed to read the 'localStorage' property`，结果作废。串行跑。
- 块夹具必须在 **600px 视口**下量（`Emulation.setDeviceMetricsOverride`）：
  1400px 视口会把夹具拉伸 2.125×，几何对比全部失效（真机比例是 1.333）。
- 真实文档夹具：`cargo test dump_real_doc_fixture -- --ignored --nocapture`
  （用户那份数学作业文档在 `.browser-check/real-scene.typ` / `real-fixture.json`）。
- 真实引擎的"这个块有没有输出"要直接看块表（`found && svg === ""`），
  **不能**看 `buildBlockCovers` 的结果 —— 那条路会把"这一轮没渲"标成 revealed，于是永远不补渲。

## 6. 和这位用户协作的老规矩（本仓库通用）

- 改 `src/` 会 HMR 到正在运行的 `tauri dev`；改 `src-tauri/` 会让 Tauri 重启应用。
- **绝不阻塞等 GitHub workflow**（不写轮询、不用 `job_output(wait: true)` 等 CI/Release）；
  报告状态最多**单次**查一次 `gh run list`。
- **发版权在用户手里**：改版本号三处 / 写 CHANGELOG / 打 tag / 发 Release，
  这四件事只在用户明确说「发 X.Y.Z」之后才做。
- **只清理自己创建的对象**：自己起的进程记 PID，自己建的文件自己删，
  别碰用户开着的窗口、端口、编辑器会话。
- 观感偏好：仿 Typora，**不要工具条**；菜单/Alt 不许夺走编辑区焦点；界面不要多余色块与凸出。
- 他不喜欢等慢测试：日常 `npm run check` + 相关单测即可，浏览器那套只在改编辑器/装饰/布局时跑。
