# 所见即所得与公式呈现

写作模式保留 Typst 源码为唯一正文；在可安全显示的地方隐藏语法或以内联 SVG 呈现公式，光标或部分选区触及语法范围时揭示源码。复杂块与块切片的坐标、生命周期和并发规则见[写作模式渲染](writing-rendering.md)。

## 扫描与装饰

`typst-lex.ts` 区分 markup、code、raw、comment、string 等上下文；`math-ranges.ts` 只在 markup 中识别公式，`markup-ranges.ts` 识别当前支持的标题、强调、行内代码、列表符号和链接。扫描必须保守：误把代码或字符串当公式会改变用户看到的文本，因此不确定时保持源码。

CodeMirror 的 StateField 维护装饰。一般标记样式始终应用；每枚标记只在选区触及该枚标记时显示其源码符号，光标只在标记后的正文中移动时，定界符仍保持隐藏。这种局部揭示避免光标在标题或强调正文中移动时整组标记出现、造成文本横跳。行内公式、围栏 raw 与复杂块按各自规则展开，不套用普通标记的局部范围。零长度内容不能创建 `Decoration.mark`。widget 构建和装饰收集中的异常须被隔离并回退为可编辑源码，不能让异常穿过编辑器事务。

选区完整覆盖单行公式时可保留呈现并显示淡色选择层，使复制或替换整个公式仍然可行；部分覆盖或光标在公式内部则揭示源码。跨行行间公式是例外：不要把整行 contenteditable=false 的 block widget 留在完整选区下，否则输入可能落到下一行。当前单行行间公式以公式区间装饰、行级居中，选择判定必须依据实际被装饰区间，并在请求和装饰两处使用相同口径。

## 公式编译契约

前端按可见、未缓存的公式发起请求，父级去重并排队调用 Rust `compile_math`。缓存键要涵盖公式文本、风格、编译上下文和字号。正文中的可用单行顶层 `#let` 定义可加入上下文；多行、含内容块或尚未完成的定义不参与。文档定义编译失败时可退回基础前缀重试，失败始终保留源码，不显示空 widget。

`MathOutput` 提供成功标志、SVG、宽高、基线和错误信息；**长行内公式还带 `segments`**（按顶层运算符切开、各自编译的片段，`+ - = < > <= >= != == -> <-`，括号内的运算符不算顶层，短公式不分段、任一片段编译失败就整体退回整块）。这是为了对齐折行：Typst 会在行内公式的运算符处折行，而浏览器把整块 SVG 当不可断的原子 —— PKU 实测同一段浏览器折 4 行、Typst 3 行，位置与行数两条门槛同时红。前端 `MathWidget` 把片段渲染成多个 `inline-block`、片段之间插 `<wbr>`（被完整选中时仍整块渲染）。注意 `typst-engine` 的 `compileMath` 是逐字段重建结果对象的，新增字段必须显式带出去，否则整条链路白做。SVG 为贴边透明底，尺寸以 pt 表示。公式布局要把 Typst 绘制的墨迹纳入页面范围：文字使用 glyph ink edges，图形使用 shape bbox，并递归处理 group 仿射变换。若墨迹越界，再以显式页面尺寸和 padding 重排；正常情况不应无条件多编译一次。基线测量用双页探针：第二页放相同公式和低于基线的零宽参照，`page.frame.baseline()` 不能视为字形基线。详见 Rust `typst_world/math.rs`。

源码模式默认 10.5pt（14 CSS px）；写作模式跟随文档正文点数，公式 SVG 的 pt 尺寸与编辑器 CSS 点数按同一尺度使用。Rust 与前端默认值须同步。暗色下公式黑字可反色显示；CodeMirror `EditorView.theme` 不支持 `&dark` 选择器，应通过主题 class 处理。

独占单行的行间公式仍使用行内 widget，并通过独立行装饰居中；跨行行间公式才使用块级 widget。围栏代码可渲染为纯文本代码块。块级装饰必须来自 StateField。空公式应安全回退或显示空结果，不得让排版错误破坏编辑。

展开公式时的滚动稳定由 `planEditReserve` 计算临时占位：仅补 `max(0, 渲染盒高度 − 源码自然高度)`，且不得超过渲染盒或一个编辑器可视高度；无状态计算保证反复进出不会累积空白。源码比渲染盒高时允许自然增长。占位是 StateField 提供的块装饰，不能从 ViewPlugin 间接添加块级装饰。

公式、行间公式和围栏代码 widget 的按下事件通过 `revealSourceAt` 处理。选择与 `anchorPosEffect` 滚动目标在同一事务提交；只有左键钉住点击行。高块没有块内字符命中时，只有点击第一行附近才钉锚，点中段/底部只设置源码位置，避免把块首强行钉到鼠标坐标而将页面拉回顶部。模式切换前记录光标相对滚动容器的位置，布局后再恢复；恢复回调通过 epoch 和当前 EditorView 身份校验，连续切换或销毁时旧回调作废。目标原在视口外时不强行滚入。

## 性能与兼容边界

- 公式只对视口附近且未缓存、未被编辑的范围请求渲染；光标/选区内的公式保留源码，避免每次按键编译。
- 文档扫描结果通过 `live-preview/doc-scan.ts` 按 CodeMirror `Text` 身份复用。修改文档才重新扫描；选区移动和渲染刷新不扫描整篇。
- 公式请求受编译调度器约束；返回结果通过 StateField 刷新装饰。刷新按动画帧合并，文档切换或过期结果不能应用到新会话。
- `$` 自动配对只在空选区且输入恰好为 `$` 时介入：单独一行生成行间公式空架，行内生成配对；右侧已有闭合 `$` 时优先跨过它。代码/raw/comment/string、转义符及已有公式等上下文保持默认输入。对应退格可一次删除空配对。IME 或异常路径必须回到 CodeMirror 默认输入，不吞字。

局部 SVG 没有文本层；公式无法呈现或上下文不完整时显示源码。不要用 CSS 近似替代 Typst 排版，也不要为追求“总是渲染”而猜测不可逆结构。
