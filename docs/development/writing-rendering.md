# 文档模式渲染与交互

[返回文档索引](../README.md)

## 完整编译结果是文档主体

正文、公式、表格、图片、宏输出、导入内容、页边距和分页全部由 Typst 排版。`PreviewPane.svelte` 按页序直接显示 `compile_doc` 的完整 SVG。前端负责等比缩放、滚动、主题滤镜与光标，不根据编辑器宽度注入页面设置。

不同纸型的页面按共同缩放比例显示，相对宽度保持不变。100% 时最宽页铺满预览栏，窗口宽度变化会持续更新显示尺寸；用户放大可使页面超出栏宽并横向滚动。这些展示变化不触发 Typst 重新排版。页间分隔线属于展示层；深色滤镜不修改编译产物与 PDF。

前端已删除 `live-preview`、公式队列、块装饰、字体补偿、强制断点、带高盒和空行压缩，不再调用 `compile_blocks` 或 `compile_math`。

## 在原位置展开源码

点击正文定位输入；行侧、行间与页边距空白定位到最近的实际排版位置，正文上方/下方空白落到该页视觉首/尾。纸张外侧与页间空白先选择最近页，再用该页的真实几何定位；不会插入空格、换行或跨页借用字形。点击公式或脚本输出，在原位置展开该表达式的完整源码，包括多行内容。`document-interaction.ts` 用现有 Lezer 语法树确定完整 `$...$` 或由 `#` 开始的表达式，包含函数名起点和参数；未完成语法退回源码行。

`document-projection.ts` 只改变本轮编译输入：把选中表达式替换为 Typst raw，自动选取不会与源码冲突的反引号围栏。多行源码使用块级 raw；声明保留原有作用域和副作用，再显示其源码。整篇文档重新由 Typst 编译，展开内容的字体、尺寸、换行和后续分页也由引擎决定。Esc 恢复正常编译输入，再编译整页。

同一个 `Editor.svelte` 实例始终持有原文档、选区与撤销历史。文档模式把它作为透明输入层，定位在页面光标附近以承接键盘和输入法；它不绘制正文或展开内容。源码模式正常显示编辑器与整页预览。展开范围随源码事务映射；投影中的原文位置、编译位置与诊断通过映射换算，临时围栏不进入编辑器、保存、会话或 PDF。

没有可定位输出的空白页、无法命中的输出和首编译失败可通过 Ctrl+E 或页面聚焦时的 Enter / F2 继续编辑。菜单、弹窗和诊断浮层优先处理自己的 Esc。模式切换不重建编辑器；离开展开态会恢复原文的编译结果。

输入仍通过 CodeMirror 修改唯一源码，`doc` 和 `editorDoc` 每次同步。保存、新建、打开、重读、窗口隔离和会话恢复复用原来的文件流程，不产生隐式写盘。文档模式保留 Typst 段落换行与列表键位；这些只决定写入什么源码。

## 整页命中与光标

`compile_doc` 在导出 SVG 的同一轮排版里收集帧几何，返回 `geometryId`。`document_geometry.rs` 按编号缓存至多 16 份最近产物，多个窗口使用各自编号；编号被淘汰后返回空命中。

- `document_hit_test` 使用从 1 开始的页号与页面 pt 坐标，返回编译源码 UTF-8 字节偏移和光标位置。重叠背景、图片与文字优先定位文字。
- `document_cursor` 把编译源码偏移映射到页面光标；没有对应输出时返回 `null`。
- 收集几何时按 Typst 的嵌套坐标变换处理位移、旋转与缩放，光标携带变换后的方向。
- 前端先将编译偏移换成 UTF-16，逆映射到原文，再减掉前缀；光标定位使用反向路径。前缀输出提示在设置中编辑。
- 光标画在 SVG 之外，随页面缩放；源码不映射到输出时隐藏光标，不猜测版面位置。

当前交互只编辑主文档；导入文件和没有可用源码 span 的合成输出不能保证精确定位。重复宏输出优先使用点击的那份几何。交互覆盖率不影响完整结果的显示。

## 调度、过期结果与合成

两种模式共用 `document-compile-scheduler.ts`：150ms 尾随去抖，最多一个在途编译与一份待执行需求。启动、设置保存、源码展开与收起使用立即请求；普通模式切换、滚动与容器尺寸变化不请求编译。

每次请求捕获会话号、文档修订、完整源码、展开范围、前缀、路径和字体输入。成功与失败落地前都重新核对；编辑后还没启动新编译时也不能让旧产物落地。命中额外捕获交互代次，编辑、收起和模式切换作废迟到的点击。首次保存或另存为改变相对路径解析根，需要重新编译；字体配置变化也作废旧产物。

输入法从 `compositionstart` 起暂停新编译，源码镜像仍同步；`compositionend` 后先让编辑器提交最终文本，再调度更新。组件卸载取消定时器、观察器和动画帧，使在途结果失效。

编译失败保留完整的上次成功结果，禁用旧结果的源码命中；错误只由状态栏与错误徽标呈现（预览区不画占位、更新提示和错误框，也不存在切换模式的按钮——文档模式只有文档本体，光标是唯一叠加层）。切换文件立即清空产物、光标、展开范围与旧会话交互。

验证顺序见[测试](testing.md)：先检查正常与展开状态的全部页面与真实编译产物逐节点一致，再检查点击、输入、撤销和异步作废。
