# 文档模式渲染与交互

[返回文档索引](../README.md)

## 完整编译结果是文档主体

正文、公式、表格、图片、宏输出、导入内容、页边距和分页全部由 Typst 排版。前端从 `compile_doc` 的全量或增量响应还原完整 SVG，`PreviewPane.svelte` 按页序显示，每页置于独立 Shadow DOM，隔离重复字形、渐变与裁剪 ID；SVG 原文不改写。稳定页面宿主只替换变化页，保留未变页的节点。前端负责等比缩放、滚动、主题滤镜与光标，不根据编辑器宽度注入页面设置。

不同纸型的页面按共同缩放比例显示，相对宽度保持不变。100% 时最宽页铺满预览栏，窗口宽度变化会持续更新显示尺寸；用户放大可使页面超出栏宽并横向滚动。这些展示变化不触发 Typst 重新排版，也不遍历修改 SVG。宿主按真实 viewBox 保留页面比例，支持 `content-visibility: auto` 的浏览器跳过离屏绘制；全部页面 DOM 与几何仍存在，这不是 DOM 虚拟化，不支持该属性时退化为全页绘制。页间分隔线属于展示层；深色滤镜不修改编译产物与 PDF。

前端已删除 `live-preview`、公式队列、块装饰、字体补偿、强制断点、带高盒和空行压缩，不再调用 `compile_blocks` 或 `compile_math`。

## 在原位置展开源码

点击正文定位输入；行侧、行间与页边距空白定位到最近的实际排版位置，正文上方/下方空白落到该页视觉首/尾。纸张外侧与页间空白先选择最近页，再用该页的真实几何定位；不会插入空格、换行或跨页借用字形。空白落点只移动插入点，不自动展开邻近公式或脚本；已展开的源码范围内点击空白则保持展开。行侧空白先选择最近文字行，再按横向距离定位，避免高字、小字和上标/下标把落点吸走。直接点击公式或脚本输出，在原位置展开该表达式的完整源码，包括多行内容。`document-interaction.ts` 用现有 Lezer 语法树确定完整 `$...$` 或由 `#` 开始的表达式，包含函数名起点和参数；未完成语法退回源码行。

`document-source-expansion.ts` 统一点击与光标事务的展开转换：空选区的活动端进入表达式时展开最小完整范围，范围内移动保持原归属（不改为嵌套子表达式），离开后收起或直接切换到下一个表达式。边界按移动方向判定，向右进入起点/离开终点，向左反之；输入事务则保留映射后的边界，允许编辑未完成语法。非空选区、页面拖选和合成期间冻结展开，收拢选区或合成结束后按最终光标决定；外部文档恢复不自动打开旧范围。点击空白保留前述定位规则。

`document-projection.ts` 只改变本轮编译输入：把选中表达式替换为 Typst raw，自动选取不会与源码冲突的反引号围栏。临时展开统一使用无语言 raw：当前 Typst 0.15.1 的 typ 高亮会丢失多行首行部分 token 的来源偏移，优先保证每个字符的真实光标停靠点而不是显示错误的语法着色。手动展开的多行源码使用块级 raw；`#let`、`#set`、`#show` 保留原语句执行，再显示其源码，其他表达式则被 raw 替换。整篇文档重新由 Typst 编译，展开内容的字体、尺寸、换行和后续分页也由引擎决定。Esc 恢复正常编译输入，再编译整页。

同一个 `Editor.svelte` 实例始终持有原文档、选区与撤销历史。文档模式把它作为透明输入层，定位在页面光标附近以承接键盘和输入法；它不绘制正文或展开内容。源码模式正常显示编辑器与整页预览。光标和选区保留原来的源码偏移，不因展开改写或重新定位；展开/收起后以及键盘移动时，按新产物的真实光标几何显露插入点，仅滚动越界的轴，不为保持位置改变版面。展开范围随源码事务映射；投影中的原文位置、编译位置与诊断通过映射换算，临时围栏不进入编辑器、保存、会话或 PDF。

没有可定位输出的空白页、无法命中的输出和首编译失败可通过 Ctrl+E 或页面聚焦时的 Enter / F2 继续编辑。菜单、弹窗和诊断浮层优先处理自己的 Esc。模式切换不重建编辑器；离开手动展开态会恢复正常排版输入；Esc 也退出错误区域的编辑锁；仍有错误的区域继续自动显示源码。

输入仍通过 CodeMirror 修改唯一源码，`doc` 和 `editorDoc` 每次同步。保存、新建、打开、重读、窗口隔离和会话恢复复用原来的文件流程，不产生隐式写盘。文档模式保留 Typst 段落换行与列表键位；这些只决定写入什么源码。

## 整页命中与光标

`compile_doc` 在导出 SVG 的同一轮排版里收集帧几何，返回 `geometryId`。`document_geometry.rs` 按编号缓存至多 16 份最近产物，多个窗口使用各自编号；编号被淘汰后返回空命中。

- `document_hit_test` 使用从 1 开始的页号与页面 pt 坐标，返回编译源码 UTF-8 字节偏移、光标位置与 `isWhitespace` 点击标记。重叠背景、图片与文字优先定位文字；文字块背景上的空白按正文定位，独立图形/图片仍可直接点击展开。旋转项保留自身几何，不套用水平文字行规则。
- `document_cursor` 把编译源码偏移映射到页面光标；没有对应输出时返回 `null`。
- `document_selection` 把编译源码的 UTF-8 字节范围映射到真实帧四边形，支持跨页和变换后的输出；文字背景不作为整块选区。
- 收集几何时按 Typst 的嵌套坐标变换处理位移、旋转与缩放，光标携带变换后的方向。文字光标使用字体的 ascender/descender 度量，不随小写字母、标点或空格的墨迹改变高度；真实墨迹仍用于背景和几何证明。多字素连字按 Unicode 字素边界在字形 advance 内插入停靠点，命中与选区裁剪复用这些位置，不拆开组合字符或 ZWJ emoji。
- 前端先将编译偏移换成 UTF-16，逆映射到原文，再减掉前缀；光标定位使用反向路径。前缀输出提示在设置中编辑。
- 光标和选区高亮画在 SVG 之外，随页面缩放；旋转光标先缩放方向向量，再换算 CSS 角度和高度。源码不映射到输出时隐藏光标，不猜测版面位置。点击或拖动优先保留实际命中的那份几何，避免重复宏输出把光标移到另一处。

插入光标只在输入层聚焦、窗口处于前台且选区为空时显示。移动光标重新开始可见的闪烁周期；“减少动态效果”设置下保持常亮。合成观测同时支持 DOM 事件和启用时的原生 EditContext 事件，去重并在 CodeMirror 处理最终文本后恢复调度。合成期间暂停排版，冻结同一会话最后的可见起点作为常亮光标和候选锚点，不用旧偏移定位合成后的源码；结束后切换到新编译几何。普通编辑等待排版时隐藏过期插入光标，但透明输入层保留最后锚点，不跳到窗口左上角；切换文件显式清除。失焦或非空选区不能残留插入光标。

文档模式按住鼠标左键拖动即可选择正文或已展开的源码，支持反向、跨行、跨页选择；移到预览边缘会自动滚动，松开后停止。选区同步到同一个 CodeMirror 实例，右键菜单、复制、剪切、输入替换和模式切换复用真实源码选区，不写盘，也不产生额外撤销步骤。拖动经过公式或脚本不自动展开、不触发重新编译；单击仍定位并按原规则展开表达式。点击允许 5px 内的轻微抖动；超过阈值后，即使回到起点或离开预览区域也不会误判为单击。取消指针手势停止滚动并作废在途拖选。触屏轻触保留定位，触屏滚动不改为鼠标拖选。

命中只查询目标页的几何，源码光标使用区间索引，保留重复输出的既有优先序。前端用编译快照的稀疏 UTF-8/UTF-16 索引换算坐标；页面选择二分测量宿主，不扫描全部 SVG。外链通过事件 composed path 识别，源码模式预览的原生选区按 Shadow DOM 宿主归属判断。点击或拖动选区同步不触发键盘进入公式/代码时的自动展开。

当前交互只编辑主文档；导入文件和没有可用源码 span 的合成输出不能保证精确定位。点击重复宏输出时使用命中的那份几何，但后续按源码偏移调用 `document_cursor` 不携带输出实例提示，可能定位到另一份输出。交互覆盖率不影响完整结果的显示。

## 调度、过期结果与合成

两种模式共用 `document-compile-scheduler.ts`：150ms 尾随去抖，最多一个在途编译与一份待执行需求。启动、设置保存、点击或键盘导航引起的展开与收起使用立即请求；输入形成或改变展开仍共用编辑去抖，不逐键立即重编译。已经自动显示的错误源码进入/离开编辑锁不重复排版，除非需要作废在途请求或收起已修好的源码；错误回退或在途编译时切换模式也重新请求，以按当前模式处理错误。正常稳定状态的模式切换、滚动与容器尺寸变化不请求编译。

每次请求捕获会话号、文档修订、完整源码、展开范围、前缀、路径和字体输入，以及本会话已经落地的页面基准。增量响应仅按同位置指纹复用该基准中的 SVG；首次请求与切换文件不携带基准，在途或回退中的临时产物不会更新它。几何与诊断仍重新生成。成功与失败落地前都重新核对；编辑后还没启动新编译时也不能让旧产物落地。命中额外捕获交互代次，编辑、收起和模式切换作废迟到的点击或拖选。拖动固定按下锚点，仅保留一个在途命中和一个最新落点，松开后的最终落点也会提交；光标与高亮查询分别检查代次和产物编号，不互相作废，也不回写新会话。首次保存或另存为改变相对路径解析根，需要重新编译；字体配置变化也作废旧产物。

输入法从 `compositionstart` 起暂停新编译，包括在途失败后的错误恢复重试；延后的恢复需求留给合成结束后重新诊断，源码镜像仍同步；`compositionend` 后先让编辑器提交最终文本，再调度更新。组件卸载取消定时器、观察器和动画帧，使在途结果失效。

文档模式编译出错时，根据主文档诊断把出错的完整公式或脚本临时替换为 Typst raw 源码，再重新编译整篇文档；正常区域继续由 Typst 排版。嵌套表达式回退到外层调用，错误声明不再执行，依赖它的后续错误调用也会展开。残缺语法无法局部恢复或错误级联过多时，有限重试后回退为整段正文源码。每次编辑都从当前原文重新诊断。点击错误源码后，在该区域持续输入时保留源码展示，修好即清除诊断，但不突然收起；光标移出该区域、点击其他区域或按 Esc 后恢复正常排版。未进入编辑态的错误区域修复后自动恢复。回退产物保留原文位置映射，可以点击、输入和撤销；错误仍由状态栏、错误徽标与编辑器诊断呈现，临时围栏不进入保存、会话或 PDF。

源码模式不做错误回退。前缀、外部文件与不可定位的错误无法映射到正文区域时，保留完整的上次成功结果并禁用旧结果的源码命中。预览区不画占位、更新提示或错误框，也不存在切换模式的按钮；源码回退属于文档本体，仅光标和选区高亮作为叠加层。切换文件立即清空产物、光标、展开范围与旧会话交互。

验证顺序见[测试](testing.md)：先检查正常与展开状态的全部页面与真实编译产物逐节点一致，再检查点击、输入、撤销和异步作废。

## 可行性与扩展评估

以下总结基于 `c957023`（Typst 0.15.1）的源码核查与真实编译实验。**实验记录属于该研究基线，并非所有边界都仍未处理；后续已加入上文所述的错误区域源码回退与重新诊断。性能实现与可复现基准见下方当前章节；这些测量仍是隔离探针结果，不能当作目标平台的性能承诺。**

当前路线适合“源码驱动的可交互排版文档”：完整 Typst 排版、唯一源码、CodeMirror 事务和同轮几何值得保留。显示任意可编译内容，不等于能无歧义地直接编辑任意输出；不应从 SVG 反推可写文档结构，也不应承诺动态宏的通用双向转换。

### 编辑与投影边界

研究基线中，透明编辑器管理选区和键盘输入，但页面没有可视选区、拖选、排版行导航或光标自动滚动。当前已支持可视选区、拖选和真实插入点显露；排版行导航仍未实现。每次源码变化清除页面光标，等去抖与成功编译后恢复；空行、注释和无输出源码没有天然定位几何。持续输入和真实中文 IME 的预编辑反馈不能由人工 `CompositionEvent` 验收代替。

[`document-projection.ts`](../../src/lib/core/document-projection.ts) 仅投影本轮编译输入，不保证原始程序语义不变。原文与投影的同版本编译对照确认：

| 情形 | 实验结果 | 含义 |
| --- | --- | --- |
| `#show raw: it => []` 后展开公式 | raw 源码被隐藏，投影仍编译成功 | 展开仍受用户 show 规则影响 |
| 展开 `#context { c.step(); [标记] }`，其中 `c = counter("x")` | 后续 counter 从原文的 1 变成投影的 0 | 替换表达式也移除了副作用 |
| 展开 `$unknown_variable$` | 原文报错，raw 投影成功 | 展示有效性不等于原文有效性 |
| 240pt 页面中的 320 字符 raw 行 | 几何最右延伸到约 1,719pt | 引擎排版不保证展开源码自动折行或完整可读 |

研究基线的 [`runCompile`](../../src/routes/+page.svelte) 只接收投影诊断。当前 [`compileDocumentWithFallback`](../../src/lib/core/document-error-fallback.ts) 已重新诊断当前排版输入并保留回退前的诊断，但手动展开仍可能遮蔽被 raw 替换的表达式错误。保存保留原文，PDF 重新编译原文，因此展开预览成功仍不能证明文件可正确导出。后续宜增加独立的原文验证，与展示产物按同一会话、源码及上下文修订作废；原文验证不导出 SVG 或收集几何，原文报错也不应无条件禁用可编辑的有效投影。不可见或越界展开需要可操作的源码模式回退。

### 几何与输出身份

[`collect.rs`](../../src-tauri/src/block_geometry/collect.rs) 与 [`document_geometry.rs`](../../src-tauri/src/document_geometry.rs) 的真实帧探针确认了以下边界：

- 同一内容被宏输出两次：点击第二份后，按源码偏移重新定位可回到第一份。源码范围不是输出实例身份。
- `office` 的 `ffi` 连字对应一个 glyph，内部两个源码位置显示在同一端点；组合字符也可能对应多个源字节。合法光标停靠点不能按字节、码点或 glyph 数简单推算。
- RTL 字形的源码范围与视觉顺序相反，但当前源起点仍被画在字形左边；需要方向与光标 affinity 模型。
- `#upper("ß")` 输出的两个 `S` 的 span 对应函数名里的 `u`、`p`，不是字符串中的 `ß`。span 是来源提示，不保证对应输出字面内容；展开整个表达式是合理回退。
- 裁剪框外的文字仍被收集并可命中；几何需要裁剪与可见区域，而非只有轴对齐包围盒。
- 当前产物之后生成 16 个新快照，当前几何可被淘汰。编号防止误用其他产物，但全局 FIFO 不保证窗口的当前产物一直可交互。

扩展模型至少需要文件身份、原文/投影坐标域、输出实例、合法光标停靠点、基线与变换、裁剪、阅读顺序和来源分类。输出实例只在当前产物内有效，不能假定 Frame 路径在重排后稳定；跨产物重匹配需要源锚点和页/位置提示，歧义时回退。

### 当前性能实现与基准

- [`collect.rs`](../../src-tauri/src/block_geometry/collect.rs) 每轮遍历主文档语法树建立 Span 区间索引，未知 Span 仍通过 `World::range` 解析；按字体、字号和 glyph ID 缓存墨迹度量。两类缓存只属于本轮 World，不跨源码修订复用。主文档字形只计算一次变换矩形，轴对齐平移/缩放采用两角快路径，旋转与斜切保留四角计算。
- [`svg_cache.rs`](../../src-tauri/src/typst_world/svg_cache.rs) 使用 [`svg_fingerprint.rs`](../../src-tauri/src/typst_world/svg_fingerprint.rs) 的默认 SVG 输入指纹，忽略不可见源码元数据，避免段落变化导致未变页重传。请求 `knownPages` 与响应 `pageKeys` 按同位置匹配，复用页以 `null` 引用前端基准。缓存与版本边界见[编译后端](compiler-backend.md#编译链路)；几何与诊断仍每轮重新生成，复杂重排不保证只传一页。
- [`source_cache.rs`](../../src-tauri/src/typst_world/source_cache.rs) 复用有界主源快照，通过 UTF-8 安全差分调用官方增量解析；旧 World 保留不可变修订，依赖仍每轮读盘，不写回原文。字体元数据与标准库共享，命令结束清理 comemo 冷历史。
- [`document-pages.ts`](../../src/lib/ui/document-pages.ts) 管理页级引用隔离与节点复用；共同缩放只改变宿主宽度，滚动光标测量只读目标页。页面输入指纹按响应式输入变化生成一次，坐标索引按源码快照建立，避免每次移动光标序列化、拆行或扫描全文。

原生探针 [`performance.rs`](../../src-tauri/src/typst_world/tests/performance.rs) 覆盖 1/10/50/100 页中英正文、公式与表格；[`edit_performance.rs`](../../src-tauri/src/typst_world/tests/edit_performance.rs) 对真实外部文件只读取样。以下同机 Cargo **debug** 对照以 `8da9172` 为基线，每份先执行输入、删除、段落与撤销，再测试 43 个不同输入，共 150 轮；每轮独立直接 SVG 导出校验完整重建。表中为原生各阶段时间之和（ms），不含 oracle、真实 IPC、DOM 或输入去抖。

| 只读样本 | 不同输入中位数：前 → 后 | 样本 p95：前 → 后 | 单次段落编辑：前 → 后 |
| --- | ---: | ---: | ---: |
| 高等代数，6 页 | 186.53 → 164.22 | 228.10 → 184.15 | 1082.91 → 256.60 |
| 数学分析 A，5 页 | 208.50 → 182.73 | 233.50 → 200.53 | 778.99 → 545.24 |
| 数学分析 B，5 页 | 133.50 → 101.25 | 156.98 → 125.55 | 497.80 → 107.97 |

World 构建中位数从约 17–21ms 降到 1–2ms。代数样本的段落编辑实际改变 2 页，传输从 6 页 / 2,244,126 字节降到 2 页 / 627,577 字节；分析 B 从 5 页降到 1 页，分析 A 确实改变全部 5 页，仍全传。撤销不保证加速：分析 A/B 此次由约 149/77ms 升到 162/88ms；缓存清理和不同增量 AST 身份会影响引擎热命中。缓存淘汰成本已计入优化后分段，中位数约 3.6ms、最大约 13.7ms。

该 150 轮探针进程峰值 RSS 从约 964 MiB 降到 713 MiB，包含字体、独立 oracle 与历史快照，不能当成生产应用内存预算或泄漏证明。当前 100 页复核仍只传 1 页，页面 JSON 103,649 字节；World / Typst / 几何 / 差量导出中位数约 11/239/150/24ms，索引建立约 25ms、JSON 约 3ms。大文档不是所有阶段都继续变快，测量也有机器负载波动；首次导出、全页重排与超预算缓存仍有完整成本。

浏览器 [`document-performance.mjs`](../../scripts/browser-check/document-performance.mjs) 将真实夹具重复为 100 页，隔离比较整篇 DOM 替换与页级更新。本机 headless Chromium 一次测量为单页更新 139.2 → 1.3ms（含强制布局），首轮 132.2 → 91.1ms；数值随机器与浏览器变化，不设固定时间 CI 门槛。验收同时检查全部节点、99 页复用、离屏占位与末页命中，以及直接 SVG / Shadow DOM 首屏像素一致。该探针不代表动态编译 100 页或所有模板的视觉等价。

复现命令见[测试](testing.md)。以上原生分段与 Chromium 静态夹具不是目标平台的端到端验证；仍需 Windows 发布版 WebView2 的真实 IPC、中文 IME、复杂模板、大范围重排、持续编辑 p95 与峰值内存测量。几何仍按份数淘汰，热 comemo 缓存没有内存预算，当前产物窗口租约尚未实现。

### 演进顺序与待验证项

| 阶段 | 建议方向（未实现） | 验收重点 |
| --- | --- | --- |
| 正确性 | 独立原文验证、不可见/越界展开回退、裁剪、RTL、重复输出实例、当前几何租约 | 真实编译反例；原文保存、撤销和导出不变；晚到结果不得落地 |
| 后续性能优化 | 真正的 DOM 虚拟化、几何内存预算、复杂重排下的输出复用 | 完整产物与尺寸占位不变；缓存淘汰可恢复；记录端到端成本 |
| 视觉编辑 | 可见选区、排版行导航、拖选、滚动跟随和真实 IME | 中文、emoji、连字、RTL、跨页、缩放、展开与编译失败状态 |
| 容量与扩展 | 虚拟化、依赖监听与失效、热缓存预算、全局编译队列公平性、多文件 | 发布版 WebView2；复杂模板；持续编辑 p95、峰值内存、多窗口与导出竞争 |

格式命令、大纲、查找及静态表格/图片参数操作可继续基于源码事务扩展。持久 Source、依赖监听或后台验证不能引入隐式写盘；全局队列可合并过期展示需求，但不能丢弃用户明确请求的导出。若仍只绘制已编译正文，输入反馈就有去抖、编译、输出和 DOM 的延迟下限；是否允许局部临时编辑层属于产品契约选择，不能伪称为行为不变的内部优化。

[Tinymist](https://github.com/Myriad-Dreamin/tinymist) / [typst.ts](https://github.com/Myriad-Dreamin/typst.ts) 均有持续维护的上游；本轮保留内嵌 Rust 引擎，未新增运行时依赖，也未完成迁移成本验证。若评估迁移，仍需核实语义诊断、源/输出跳转、持久编译状态和增量渲染，而不把语言服务直接等同于通用视觉编辑器。验证层级与桌面要求仍以[测试](testing.md)为准。
