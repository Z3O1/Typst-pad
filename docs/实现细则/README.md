# 实现细则（CLAUDE.md 的详版）

`CLAUDE.md` 只写规则；这里放规则背后的**实测数据、踩坑经过与完整论证**。规则本身以 `CLAUDE.md` 为准，本目录用于追根因、判断某条红线能不能动、做回归时查现场证据。

- 版本口径：**0.10.0**（2026-09-23）；逐版变更看 `CHANGELOG.md`，提交脉络看 `git log`。
- 内容与 `CLAUDE.md` 对应小节**不再逐字一致**（该说法 2026-09-19 起过期）：分册是**详版**（实测数据 / 踩坑经过 / 完整论证），`CLAUDE.md` 已瘦身为**规则版**（只留规则 + 26 条一句话红线 + 文档地图）。规则以 `CLAUDE.md` 为准，细节以本目录为准。
- 改了 `CLAUDE.md` 的规则时，把新的实测数据/踩坑经过补进对应分册；**不要反过来只改这里**。
