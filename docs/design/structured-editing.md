# 行内原子与有限结构化编辑（设计）

[返回文档索引](../README.md) · 当前实现状态见[可编辑子集](../development/writable-subset.md)。

**本文是设计与任务拆分，不是现状**：只有明确标「已实现」的条目才在产品里生效；其余是候选方案，
实施前必须复核代码、夹具与真实排版。源码始终是唯一文档状态，任何结构化编辑都只是**源码修改入口**，
不引入第二份富文本文档模型，也不实现"改排版结果再逆向生成 Typst"。

## 行内原子节点（任务 3）

行内原子 = 在**真实文本块内部**由局部呈现替换的构造。它只能作为真文本中的局部呈现与源码入口，
不得引入第四种块级形态；与块切片、其它 replace 装饰或引擎断点重叠的原子一律不开放。
以行内公式为参照，每一类先定义下表五列，再实现；**上一种稳定后才开放下一种**。

| 语法 | 精确源码范围 | 可见呈现来源 | 点击 / 键盘进入时的局部源码揭示 | 选区覆盖规则 | 编辑后的失效规则 |
| --- | --- | --- | --- | --- | --- |
| 行内公式 `$…$` | `Equation` 节点（**已实现**） | 独立 `compile_math` 的 SVG（`MathWidget`） | 光标或部分选区进入即展开源码 | 完整覆盖保留呈现并叠淡色选择层；部分覆盖展开 | 公式文本变化 ⇒ 缓存键变化，旧结果丢弃 |
| 行内 raw `` `…` `` | 单行 `Raw` 节点（候选） | CSS 等宽的代码文本 + `cm-markup-raw` 标记 | 触及任一侧反引号时露出 | 完整覆盖可整体复制；部分覆盖展开 | 文本变化 ⇒ 重新扫描装饰 |
| `#link("url")[文字]` | `Code`（`#link(...)`）+ `ContentBlock`（候选） | 正文文字 + 链接样式；URL 不显示、原样留在源码 | 触及 `#link(` 或 `]` 时露出 | 覆盖整个构造可整体复制 | URL 或文字变化 ⇒ 重新扫描装饰 |
| `@key[p.~7]` | `Ref` 节点 + 补充 `ContentBlock` | **当前无独立呈现**：显示源码形态 | 恒为源码 | 无 | — |
| `<label>` | `Label` 节点 | 不显示 | 恒为源码 | 无 | — |
| 脚注 `#footnote[…]` | `Code` + `ContentBlock` | **无**：正文被排到页底，证明 `out-of-band` | 整块切片 / 源码 | 无 | — |

约束：

- 原子区间不能与块切片、其它 replace 装饰或引擎断点重叠；不能破坏带高盒、IME 组合输入、拖选或事务。
- 由宏、复杂 show rule 或动态表达式生成、不能唯一映射的可见内容继续由整块切片承载。
- 每开放一种语法，都补"源码往返 + 浏览器交互"验收；真实排版片段无法安全裁出或定位时保留切片，
  并记录具体原因（见[可编辑子集](../development/writable-subset.md)的现状表）。
- 不为了让引用/公式"更好看"而改排版结果再逆向生成源码；引用若要显示编号，必须找到
  "只编辑补充内容、编号仍由 Typst 画"这类不逆向的方案，否则维持源码形态。

## 有限结构化编辑（任务 5）

只列各自**可精确修改的源码子集**、交互与验收条件；本阶段只交付设计，不在缺少交互定义时制作通用编辑器。
凡"变量、循环、函数生成、合并单元格或未知参数"一律保持源码编辑。

### 1. 受限表格 `#table(...)`

- **可改子集**：静态、逐行字面量单元格 —— `columns:` 是字面量数字，单元格都是 `[文字]` 形式，
  没有 `rowspan`/`colspan`、没有函数调用与变量；每格能唯一定位到某个 `ContentBlock` 的字节区间。
- **交互**：点击某格 → 光标落到该格的源码区间（复用"点击切片 → 命中"的同类几何链路）；
  输入直接改源码，不整表重序列化。
- **验收**：改一格后源码只变那一格、其余参数逐字不变；含变量 / 循环 / `#for` / 合并单元格 /
  未知参数 ⇒ 整表切片或源码。
- **拆分**：① 后端给出静态单元格的源码区间（新字段，缺省 = 不支持）；② 前端点击定位；
  ③ 逐格编辑的源码往返与浏览器交互。

### 2. 图片属性 `#image("path", width: …, height: …)`

- **可改子集**：路径与尺寸参数是**字面量**时，只改对应参数值的源码区间（保留引号、单位与其余参数）。
- **交互**：选中图片（切片）后由属性面板发起 —— 面板只是**源码修改入口**，不保存独立配置副本。
- **验收**：改尺寸只动那个字面量；路径是变量 / 拼接 / 包资源 ⇒ 只读或源码。
- **前置**：路径校验、资源复制与统一写入链必须沿用现有原生路径与写盘规则。

### 3. 图注 `#figure(..., caption: [...])`

- **可改子集**：`caption` 是单个 `ContentBlock`、其余参数静态时，只改 caption 的正文区间。
- **验收**：换字不动其余参数；`numbering` / 交叉引用状态变化后资格重算（`fresh` 失效、退回切片）。

### 4. 引用选择器（`@key` 的补充内容 `@key[p.~7]`）

- **可改子集**：`Ref` 节点的补充 `ContentBlock`；`key` 本身可改时也只在标识符区间内替换。
- **交互**：目前**不开放**（无独立呈现）。开放前必须先解决"显示编号 → 逆映射回源码"这条否决项，
  或只编辑补充内容、编号仍由 Typst 画。
- **验收**：改补充内容后源码只变那一段；引用目标不存在 / 编号样式变化 ⇒ 资格重算。

### 5. 设置面板的边界

`#set` / `#show` / `#let`、导入及注释维持"无输出时隐藏、按需显露源码"的现有语义；将来的设置面板
也只能成为源码修改入口，不能保存独立配置副本。
